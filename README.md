# SmartShop

A modern React e-commerce website built as my SheCanCode Frontend Capstone Project.

## Live Demo

https://my-capstone-project-eta.vercel.app/

## Features

- Responsive design
- Product search
- Categories
- Wishlist
- Shopping cart
- Product details
- Quick View
- Newsletter subscription
- Contact page
- React Router navigation

## Tech Stack

- React
- Vite
- CSS
- React Router
- Context API
- Lucide React

## Installation

Clone the repository

git clone https://github.com/Afsah3

Install dependencies

npm install

Run project

npm run dev

## Challenges

One challenge was implementing global state management for the shopping cart and wishlist. I solved this by using React Context API.

Another challenge was making the application responsive across different screen sizes. I solved it using CSS Grid, Flexbox, and media queries.
